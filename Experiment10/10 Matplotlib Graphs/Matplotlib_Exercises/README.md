# Matplotlib Graph Exercises

Install Matplotlib from a terminal in this folder with `python -m pip install -r requirements.txt`.

Run any example with `python q01_line_plot.py`, replacing the filename as needed. Each program opens a chart window. The save-chart exercise also writes `weekly_attendance.png` beside its Python file.

## Exercises

1. Create and label a line plot with a title, axes, grid, and legend.
2. Compare subject marks with a bar chart.
3. Show the relationship between study hours and exam marks with a scatter plot.
4. Present revenue and order counts in side-by-side charts.
5. Save a labeled chart as a PNG image.

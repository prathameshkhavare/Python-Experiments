# 10 Matplotlib Graphs

## Syllabus focus

Create and label charts with Matplotlib to communicate patterns in data.

## Learning outcomes

- Prepare values for plotting and create a figure with axes.
- Draw and customize line, bar, and scatter plots.
- Add titles, axis labels, legends, and readable ticks.
- Save or display a chart and choose a chart type that fits the data.

## Repository coverage

The `Matplotlib_Exercises` folder contains five runnable examples: a line plot, a bar chart, a scatter plot, side-by-side comparison charts, and a chart saved as a PNG image. Install Matplotlib with the requirements file in that folder.

# Experiment 2 - String Programs

## Description
This folder contains Python programs based on string operations. It helps to understand and perform different operations on strings using Python.

## Topics Covered

1. Find the Length of a String
2. Count Vowels and Consonants
3. Count Digits, Spaces and Special Characters
4. Reverse a String
5. Check Palindrome String
6. Convert String into Uppercase
7. Convert String into Lowercase
8. Replace Characters in a String
9. Remove Spaces from a String
10. Find Frequency of a Character
11. Find First and Last Character
12. Find ASCII Value of Characters

## Language
Python

## Purpose
To understand different string operations and improve basic Python programming skills.

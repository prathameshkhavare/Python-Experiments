# Experiment 7 - Exception Handling

## Description
This folder contains Python programs based on exception handling. It helps to understand how to handle runtime errors and prevent program crashes using Python.

## Topics Covered

1. Introduction to Exceptions
2. Try Block
3. Except Block
4. Multiple Except Blocks
5. Else Block
6. Finally Block
7. Handling Division by Zero
8. Handling ValueError
9. Handling IndexError
10. Handling FileNotFoundError
11. Raising Exceptions Using `raise`
12. User-Defined Exceptions

## Language
Python

## Purpose
To understand exception handling concepts and learn how to handle errors effectively in Python programs.

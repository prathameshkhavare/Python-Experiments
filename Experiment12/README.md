# Experiment 12 - Django Login and Regex Validation

## Description
This folder contains Python programs based on Django web development and Regular Expression (Regex) validation. It helps to understand how to create web applications, handle user login and validate user input.

1. Introduction to Django
2. Django Project Creation
3. Django App Creation
4. Django URL Configuration
5. Django Views
6. Django Templates
7. Django Models
8. User Registration Form
9. User Login System
10. User Authentication
11. Regular Expressions (Regex)
12. Form Validation Using Regex

## Framework Used
Django

## Language
Python

## Purpose
To understand basic web development using Django and learn user authentication and input validation using Regular Expressions.

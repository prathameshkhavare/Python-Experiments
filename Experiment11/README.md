# Experiment 11 - Tkinter GUI Programs

## Description
This folder contains Python programs based on Tkinter. Tkinter is a Python library used to create Graphical User Interface (GUI) applications.

## Topics Covered

1. Introduction to Tkinter
2. Create a Basic GUI Window
3. Labels and Buttons
4. Entry Widget
5. Text Widget
6. Checkbutton Widget
7. Radiobutton Widget
8. Listbox Widget
9. Message Box
10. Frame Widget
11. Create a Login Form
12. Event Handling in Tkinter

## Library Used
Tkinter

## Language
Python

## Purpose
To understand GUI programming and learn how to create interactive desktop applications using Python Tkinter.

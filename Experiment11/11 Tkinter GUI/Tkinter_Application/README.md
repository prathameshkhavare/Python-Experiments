# Tkinter Student Registration Application

This desktop app demonstrates a Tkinter window, labels, entries, a course dropdown, a button callback, input validation, and dialog boxes.

Run it with `python app.py`. It requires Python with Tkinter available.

Email and phone formats are validated before a registration summary is displayed. Registrations are not saved to a database.

# 11 Tkinter GUI

## Syllabus focus

Build a desktop interface with Tkinter widgets, layout managers, and event callbacks.

## Learning outcomes

- Create a root window and add common widgets such as labels, entries, and buttons.
- Arrange widgets with a layout manager.
- Connect user actions to callback functions.
- Read input from a form and show a result or validation message.

## Repository coverage

The `Tkinter_Application` folder contains a Student Registration desktop app with a form, dropdown, event callback, email and phone validation, and confirmation dialogs. Registration data is displayed but not saved to a database.

Run the program with `python app.py` from that folder.

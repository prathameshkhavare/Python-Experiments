# Experiment 5 - Class Programs

## Description
This folder contains Python programs based on classes and objects. It helps to understand Object-Oriented Programming (OOP) concepts in Python.

## Topics Covered

1. Create a Class and Object
2. Constructor (`__init__`)
3. Instance Variables
4. Class Variables
5. Instance Methods
6. Class Methods
7. Static Methods
8. Encapsulation
9. Inheritance
10. Polymorphism

## Language
Python

## Purpose
To understand the basic concepts of Object-Oriented Programming using Python classes and objects.

# Experiment 6 - File Handling

## Description
This folder contains Python programs based on file handling. It helps to understand how to create, read, write, append and manage files using Python.

## Topics Covered

1. Create a File
2. Open a File
3. Read a File
4. Write Data into a File
5. Append Data to a File
6. Close a File
7. Read File Line by Line
8. Count Lines in a File
9. Count Words in a File
10. Count Characters in a File
11. Copy File Contents
12. Check Whether a File Exists

## Language
Python

## Purpose
To understand file handling operations and learn how to manage files using Python.

# Experiment 8 - Inheritance and Polymorphism

## Description
This folder contains Python programs based on inheritance and polymorphism. These concepts are important parts of Object-Oriented Programming (OOP).

## Topics Covered

1. Introduction to Inheritance
2. Single Inheritance
3. Multiple Inheritance
4. Multilevel Inheritance
5. Hierarchical Inheritance
6. Hybrid Inheritance
7. Method Overriding
8. Introduction to Polymorphism
9. Compile-Time Polymorphism
10. Run-Time Polymorphism
11. Using `super()` Function
12. Advantages of Inheritance and Polymorphism

## Language
Python

## Purpose
To understand different types of inheritance and polymorphism and learn how to implement them using Python.
